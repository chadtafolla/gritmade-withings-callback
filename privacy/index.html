Gritmade Lift: privacy policy

Updated November 3, 2026

What this is

Gritmade Lift is a personal workout tracker used by one person, its owner. It is not a public service and does not accept other users.

What data it reads

With the owner's permission, it reads the owner's own data from connected services:

  • WHOOP: recovery, sleep, strain, workouts, profile and body measurements
  • Withings: weight and body fat measurements

Where the data goes

Data is stored only on the owner's own computer, by a server that runs locally on that computer. It is not uploaded anywhere else, sold, shared with third parties or used for advertising. Access tokens are stored in a local file on that computer and are never sent to the browser or to this website.

This website only hosts redirect pages that send the sign-in result back to the owner's computer. It does not store or log any data.

Removing access

Access can be revoked at any time from the app's Settings page, or from the WHOOP or Withings account settings. Deleting the local files removes all stored data.
